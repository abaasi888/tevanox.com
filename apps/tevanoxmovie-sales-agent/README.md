# 👔 TevanoxMovie Sales Agent

**Earn by inviting friends to TevanoxMovie**

## 📱 About

TevanoxMovie Sales Agent is a dedicated app for sales agents to track referrals, earnings, and manage their network. Agents can share referral links, generate QR codes, and access marketing materials to grow their team.

## ✨ Features

- 👤 Agent Dashboard with real-time stats
- 👥 Team management and network tree
- 💰 Earnings tracking and withdrawal requests
- 📤 Share referral links via social media
- 📱 QR code generation for easy sharing
- 📊 Commission breakdown and tier progress
- 📢 Marketing materials hub
