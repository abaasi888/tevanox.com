# 🖥️ Admin Dashboard Guide

## Getting Started

### Login

1. Go to https://admin.tevanox.com
2. Enter admin email and password
3. Click "Login"

### Dashboard Overview

- **Stats Cards**: Total users, movies, agents, revenue
- **Revenue Chart**: Monthly revenue trends
- **Recent Activity**: Latest platform activity
- **Top Agents**: Best performing agents

## Content Management

### Movies

**Add Movie:**
1. Go to Movies > Add Movie
2. Fill in movie details:
   - Title, description, category
   - Genre, VJ (if translated)
   - Release year, duration
3. Upload video file
4. Upload poster image
5. Click "Add Movie"

**Edit/Delete Movie:**
- Use the action buttons next to each movie
- Edit: Update details
- Delete: Remove movie permanently

**Bulk Upload:**
- Upload multiple movies at once
- Use CSV template
- Include all required fields

### Series

**Add Series:**
1. Go to Series > Add Series
2. Fill in series details
3. Add seasons and episodes
4. Upload episode videos
5. Click "Add Series"

**Manage Episodes:**
- Add episodes to existing series
- Update episode details
- Reorder episodes

### Music

**Add Music:**
1. Go to Music > Add Music
2. Fill in music details
3. Upload audio file
4. Upload cover art
5. Click "Add Music"

**Manage Artists:**
- Add/edit musicians
- Link music to musicians

### Categories & Genres

**Categories:**
- Add new categories
- Edit existing categories
- Delete categories (if not in use)
- Organize with parent/child structure

**Genres:**
- Add new genres
- Edit existing genres
- Delete genres (if not in use)

### VJs & Musicians

**VJs:**
- Add VJ with code and language
- Edit VJ details
- Delete VJ (if not in use)

**Musicians:**
- Add musician details
- Link to genres
- Delete musician (if not in use)

## User Management

### Users

- View all registered users
- Filter by status (active/inactive)
- Search by username or email

### Agents

- View all registered agents
- View agent details:

  - Total referrals

- Toggle agent status
