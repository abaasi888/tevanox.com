# 📱 User App Guide

## Getting Started

### Registration

1. Go to https://tevanox.com
2. Click "Sign Up"
3. Fill in your details:
   - Username
   - Email
   - Password
4. (Optional) Enter agent referral code
5. Click "Create Account"

### Login

1. Click "Sign In"
2. Enter your email and password
3. Click "Login"

### Profile

- View your profile information
- Update personal details
- Change password
- View subscription status

## Browsing Content

### Home Page

- **Trending Movies**: Most popular movies
- **Latest Movies**: Newest additions
- **Trending Music**: Popular songs
- **Categories**: Browse by category

### Search

1. Click the search icon
2. Type your query
3. Filter by type (movies, series, music)

### Categories

- **Ugandan**: Local Ugandan content
- **English**: International content
- **Luganda Translated**: VJ translated content
- **Swahili Translated**: VJ translated content

## Watching Content

### Movies

1. Click on a movie poster
2. View movie details
3. Click "Play" to start watching
4. Use controls to pause, seek, adjust volume

### Series

1. Click on a series poster
2. Select a season
3. Choose an episode
4. Click "Play" to start watching

### Music

1. Click on a song
2. Click "Play" to start listening
3. Use controls to pause, skip, adjust volume

## Downloads

### Download Content

1. Open a movie or episode
2. Click the "Download" button
3. Wait for download to complete
4. Access downloads from the Downloads section

### Offline Viewing

- Downloaded content can be viewed without internet
- Access via the Downloads tab
- Delete downloads to free up space

## Subscriptions

### Plans

- **Weekly**: 7,000 UGX
- **Bi-Weekly**: 12,000 UGX
- **Monthly**: 20,000 UGX (Best value)

### Activate Subscription

1. Go to Subscription page
2. Select a plan
3. Choose payment method
4. Complete payment
5. Start enjoying premium content

## Favorites

- Add content to favorites
- Access favorites from profile
- Remove from favorites anytime

## Watch History

- Automatically tracks what you watch
- Access from profile
- Continue watching from where you left off
