# 👔 Sales Agent Guide

## Getting Started

### Registration

1. Download the agent app or visit https://agent.tevanox.com
2. Click "Register as Agent"
3. Fill in your details:
   - Full Name
   - Username
   - Email
   - Phone
   - Password
4. (Optional) Enter referral code from upline
5. Click "Register"

### Login

1. Enter your email and password
2. Click "Login"

### Subscription Requirement

To earn commissions, you must have an active monthly subscription:
1. Go to Subscription
2. Select "Monthly" plan
3. Complete payment
4. Start earning commissions

## Dashboard

### Stats

- **Active Referrals**: Users with active subscriptions
- **Total Referrals**: All users you've referred
- **Commission Rate**: Your current rate
- **Wallet Balance**: Available funds
- **Total Earnings**: All-time earnings

## Earnings

### Commission Structure

| Level | Rate | Amount (20,000 UGX) |
|-------|------|---------------------|
| Level 1 | 25% | 5,000 UGX |
| Level 2 | 10% | 2,000 UGX |
| Level 3 | 5% | 1,000 UGX |

### Earnings Breakdown

- Direct referrals: 25%
- Level 2: 10%
- Level 3: 5%

### Withdrawals

1. Go to Withdraw section
2. Enter amount
3. Provide bank details
4. Submit request
5. Wait for approval (1-3 business days)
